git::Remote::LibGitInitGuard Struct Reference

Detailed Description

The LibGitInitGuard keeps libgit2 initialized for as long as the remote exists, because the remote may outlive its Repository.

Declared before remote_ so that it is destroyed after it. Note that git_libgit2_init() and git_libgit2_shutdown() may be called safely multiple times (they keep a counter).
